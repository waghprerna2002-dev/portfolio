## 🚀 Getting Started

### Quick Start (3 Steps)

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open in browser
# http://localhost:5173
```

### Configuration

1. **Update EmailJS keys** in `src/components/Contact.jsx`
2. **Customize content** in respective component files
3. **Replace colors** in `src/styles/globals.css` if desired
4. **Add images** to `public/` folder

### Deployment

```bash
# Build for production
npm run build

# Deploy dist/ folder to Vercel, Netlify, or your hosting
```
